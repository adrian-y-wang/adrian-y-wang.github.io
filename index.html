ASL Eyebrow Tracking

A real-time webcam system that labels a signer's eyebrows as raised, lowered, or neutral. In American Sign Language, brow position is grammatical: raised brows typically mark yes/no questions, and lowered brows typically mark wh-questions. The system tracks 478 face landmarks with MediaPipe, combines brow expression scores into a weighted raise score and lower score, and classifies each frame against thresholds tuned from measured data.

Layered ASL Gloss (LAG)

A notation system for writing down ASL's non-manual grammar, such as facial expressions and spatial indexing, which standard glosses leave out. LAG stacks these layers above the signs in a format that reads like a music score, so learners can see what the face and body are doing at each point in a sentence.

Cipher Suite

A Java command-line program that encrypts and decrypts text and files with Caesar, substitution, Vigenère, and RSA ciphers. The ciphers share one class hierarchy, so each new cipher only defines how its key maps letters. RSA works on any file type by reading bytes in fixed-size chunks, with padding and sign-bit handling so decryption comes out exact.
